# P3 Requêtez une base de données avec SQL

## Contexte

Une compagnie d'assurance souhaite mieux accompagner ses clients en analysant le marché des assurances habitation.
J'ai conçu et créé une base de données à partir des contrats clients et d'un référentiel géographique des régions françaises, puis je l'ai interrogée avec SQL.

## Objectifs

- Comprendre et documenter les données
- Concevoir un schéma relationnel
- Créer la base de données et charger les données
- Répondre à des questions métier avec des requêtes SQL

## Réalisations

- Dictionnaire des données avec les types et les contraintes de chaque variable
- Schéma relationnel normalisé
- Code SQL de création des tables
- Chargement et vérification des données (contrôle du nombre de lignes)
- 12 requêtes SQL, par exemple le nombre de contrats par région, la cotisation moyenne par département ou les communes avec au moins 150 contrats
- Présentation de la méthodologie et des résultats

## Outils

SQL, SQLite, SQL Power Architect, Excel

## Compétences

- Modéliser une base de données relationnelle
- Écrire des requêtes SQL (filtres, jointures, regroupements, tris)
- Contrôler la qualité des données après chargement
